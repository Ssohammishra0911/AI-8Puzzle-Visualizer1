Introduction to the 8-Puzzle problem

The 8-puzzle is a sliding-tile puzzle on a 3×3 board holding eight numbered tiles and one empty square (the blank). A move slides a tile that is next to the blank into it, which is the same as moving the blank up, down, left or right. The task is to turn a given initial state into a given goal state using as few moves as possible.

Formulated as a state-space search problem

  • State: an arrangement of the tiles 1–8 and the blank on the board.
  • Initial / goal state: chosen by the user.
  • Actions: move the blank Up, Down, Left or Right, when the move stays on the board.
  • Transition model: swap the blank with the neighbouring tile.
  • Path cost: 1 per move, so the cost of a solution is its number of moves.

Facts worth knowing

  • There are 9! = 362,880 arrangements, but only 181,440 of them are reachable from any given state.
  • Two states are mutually reachable exactly when they have the same inversion parity. This app uses that test to reject unsolvable puzzles and to generate random solvable ones.
  • The average branching factor is about 2.67 (2 moves with the blank in a corner, 3 on an edge, 4 in the centre).
  • The hardest puzzles need 31 moves.

What this app does
  • Enter your own puzzle or generate a random solvable one
  • Run BFS, DFS, DLS, IDDLS, UCS, GBFS or A*
  • Animates the blank tile and every search step
  • Live frontier, explored list, h(n), g(n), f(n)
  • Run / Pause / Resume / Step / Reset / Speed controls
  • Side-by-side comparison of all algorithms
  • Documentation for every algorithm and heuristic
